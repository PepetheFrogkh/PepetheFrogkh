# Visuels du blog

Tous les fichiers de ce dossier sont **générés** par `node scripts/illustrations/build.mjs`,
à partir des schémas décrits dans `scripts/illustrations/figures.mjs`.

Ce sont des illustrations originales : aucune photo de banque d'images, aucun visuel repris
d'un autre site. Les chiffres qu'ils affichent sont ceux des articles correspondants.

Ne les modifiez pas à la main : relancez le script après avoir changé le schéma.

Un fichier par langue (`nom.fr.webp`, `nom.en.webp`) parce que les schémas portent du texte.
